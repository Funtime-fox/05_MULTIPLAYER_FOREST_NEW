# 05_MULTIPLAYER_FOREST 

> **Дата:** 24.11.2026
> **Автор (ФИО):** Заруба Е.А и Шорина В.М



## Описание проекта 
Многопользовательская 2D-игра, в которой игроки могут объединяться в одном мире для исследования леса, сбора ресурсов и взаимодействия друг с другом. Реализована полноценная клиент-серверная архитектура (Хост/Клиент). Игроки могут видеть передвижение и анимации друг друга в реальном времени, общаться через текстовый чат и обмениваться предметами. В проекте настроена серверная авторитетность для предотвращения рассинхронов при спавне и удалении объектов (грибов, ресурсов).

## Стек проекта 
* **Игровой движок / Платформа:** Godot Engine 4.x (версия 4.2+)
* **Язык программирования:** GDScript 
* **Дополнительные инструменты:** Git (GitHub), Aseprite (для 2D-графики) 

## Что было использовано в проекте 
* **Узлы (Nodes):** `CharacterBody2D` (игрок), `CanvasLayer` (UI меню, чат, список игроков), `Area2D` (сбор предметов), `MultiplayerSpawner` и `MultiplayerSynchronizer` (сетевая синхронизация), `LineEdit`, `RichTextLabel`, `VBoxContainer` (интерфейс).
* **Паттерны / Подходы:** Автолоад (Singleton) `Global.gd` для хранения инвентаря и реестра игроков, Сигналы (Signals) для обновления UI, RPC-вызовы (`@rpc`) для синхронизации ников и сообщений чата, Серверная авторитетность (Server Authority) при работе с предметами.
* **Ресурсы:** Кастомные 2D-спрайты персонажей (в стиле пиксель-арт), элементы окружения (деревья, лагерь), кастомные ресурсы `ItemData` для настройки предметов.

## Самостоятельные работы 
* **Имя игрока**: Да (ввод ника в NetworkUI, передача через RPC и отображение над персонажем через Label)
* **Переход на другую сцену**: Да (переход из сцены NetworkUI в игровой мир Forest после нажатия Host/Join)
* **Таб**: Да (список игроков открывается при нажатии Tab, динамически заполняется из Global.players)
* **Чат**: Да (открывается по кнопке C, отправка по Enter, закрытие по Escape, RPC-синхронизация сообщений для всех игроков)
